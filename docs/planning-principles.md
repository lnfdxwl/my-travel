# 规划原则

> 加载时机：开始规划新行程时读取。

## 通用原则

- **行程松紧**：4-5天行程最多覆盖 3 个城市，不要贪多
- **订票时机**：火车票通常提前 45 天开售，旺季（6-8月）应尽早抢
- **城市间交通**：优先选中午出发的班次（坐车避开最热时段 + 下午到达可立即游览）

## 酷热目的地（如中亚、中东、南亚夏季）

- 游览时段：07:00–11:00 和 17:00–21:00
- 回避时段：11:00–16:00（坐车换城市 或 酒店午休）
- 晚开放景点：清真寺、广场夜景通常开放到 22:00+，安排到晚间
